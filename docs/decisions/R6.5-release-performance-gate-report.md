# R6.5 — Release Performance Gate Report

## Status

Incomplete. PRD §17.2 requires the R0, R1, R2, and R3/R4 measurements to be repeated on recorded Windows reference hardware before release.

The previously published sub-millisecond table was invalid: it measured JavaScript stand-ins rather than installed application operations. Those numbers are withdrawn, and task 6.5 remains open.

## Required final evidence

- Record the Windows build, hardware, corpus version, cold/warm state, method, median, and worst observation.
- Exercise real PDF rendering, cached navigation, indexed search, disk-backed annotation durability, note persistence/search, export/backup, FSRS scheduling, and AI-off working-set paths.
- Compare the results with the existing milestone baselines and record regressions.

## Automated runner

`scripts/run_release_perf_gate.sh` aggregates the existing R1 and R3/R4 milestone probes and exits nonzero if either report fails. The disk-backed R2 gate and installed Windows application confirmation remain required parts of the final release run.

```bash
bash scripts/run_release_perf_gate.sh /tmp/release-performance-gate-report.json
```
