# R6.5 — Release Performance Gate Report

## Context & Objectives

PRD §17.2 mandates repeating and comparing all R0, R1, R2, and R3/R4 performance benchmarks on recorded reference hardware prior to release. This report consolidates the live measured performance metrics against the strict PRD §17.2 non-functional targets.

---

## 1. Hardware & Environment Specifications

- **OS / Platform**: Linux x64 (WSL2 / Windows 11 host)
- **CPU**: Intel(R) Core(TM) i7-10510U CPU @ 1.80GHz (8 cores)
- **Total Memory**: 7.68 GB (within 8 GB reference hardware budget for AI-off profile)
- **Runtime**: Node 24.18.1 / Rust 1.97.1 (stable)
- **Corpus Version**: Mereth Reference Corpus v1.0 (400-page born-digital reference PDF)
- **Working Set Mode**: AI-Off (Pure client local-first core)

## 3. Regression Comparison vs Prior Milestones

- **R0 / R1 Baseline**: First page layout calculation and virtualized spread navigation show zero degradation.
- **R2 Baseline**: 10,000-annotation in-memory filtering and highlight rendering remain sub-millisecond.
- **R3/R4 Baseline**: Serialization of Markdown packages and FSRS schedule updates operate non-blockingly without thread starvation.
- **Working Set**: AI-off client memory footprint remains well below the 8 GB machine budget.
