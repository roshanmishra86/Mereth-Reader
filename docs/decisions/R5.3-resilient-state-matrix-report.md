## 1. Executive Summary

Task 5.3 formally codifies the resilient-state matrix covering the 18 user and error conditions outlined in PRD §17.6 and Appendix A. For every state, Mereth Reader guarantees:
1. **Honest telemetry:** Real error messages, status codes, and non-misleading indicators.
2. **Work preservation:** Prior work (annotations, reading progress, notes, SQLite tables, dirty buffers) is never discarded silently.
3. **Usability boundary:** Clear articulation of features that remain fully functional despite the failure.
4. **Actionable recovery:** Deterministic, safe next action offered to the user (e.g. re-anchor, locate file, retry, restore backup).
