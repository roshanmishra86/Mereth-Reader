## 1. OQ-11 — Markdown Front-Matter Fields and Default Note Templates

### Decision
Standard Markdown notes in Mereth Reader use a structured YAML front-matter block with typed fields, accompanied by four built-in, user-customizable templates: `source_note`, `concept_note`, `scratch_note`, and `evidence_block`.

### Front-Matter Schema (YAML)
Every exported or persisted note front matter adheres to the following specification:
```yaml
---
id: "note-uuid-v4"
title: "Title of the note (claim/question for concept notes)"
type: "concept" # 'source' | 'concept' | 'scratch'
created_at: "2026-08-21T04:00:00Z"
updated_at: "2026-08-21T04:00:00Z"
document_id: "doc-uuid-v4" # optional, present for source notes
source_title: "Title of Source Document" # optional
source_author: "Primary Author" # optional
source_year: 2024 # optional
doi: "10.1000/182" # optional
tags: ["memory", "learning"]
provenance: "user_authored" # one of the 6 PRD §16.1 provenance values
---
```

### Built-in Templates
1. **Source Note (`source_note`):**
   ```markdown
   ---
   title: "{{title}}"
   type: "source"
   document_id: "{{document_id}}"
   source_title: "{{source_title}}"
   source_author: "{{source_author}}"
   source_year: "{{source_year}}"
   doi: "{{doi}}"
   tags: {{tags_json}}
   ---

   # Source Note: {{title}}

   **Reference:** {{citation_formatted}}
   **Document:** [Open in Mereth Reader]({{mereth_document_url}})

   ## Summary & Core Claims
   -

   ## Evidence & Key Passages
   {{evidence_blocks}}
   ```

2. **Concept Note (`concept_note`):**
   ```markdown
   ---
   title: "{{title}}"
   type: "concept"
   tags: {{tags_json}}
   ---

   # {{title}}

   ## Core Thesis


   ## Supporting Evidence & Arguments


   ## Open Questions & Backlinks
   -
   ```

3. **Scratch Note (`scratch_note`):**
   ```markdown
   ---
   title: "{{title}}"
   type: "scratch"
   tags: []
   ---

   # Scratch: {{title}}


   ```

4. **Evidence Block (`evidence_block`):**
   ```markdown
   > {{quote}}
   > — {{citation_formatted}} [Mereth Link]({{mereth_annotation_url}})

   {{comment}}
   ```

## 2. OQ-12 — Citation-Style Formatting vs Editable Metadata + References

### Decision
**Editable metadata, human-readable references, and `mereth://` deep links; no CSL rendering engine in v1.**

### Rationale
- Embedding a full Citation Style Language (CSL) formatting runtime and style repository adds significant bundle size, complex dependency graphs, and offline asset overhead without advancing the core desktop reading and review loop.
- Mereth Reader’s focus is lightweight, robust, portable knowledge synthesis. Standard human-readable citation strings (`Author (Year), p. X`) combined with immutable deep links (`mereth://document/{id}?page=X&annotation=Y`) paste cleanly into Obsidian, Logseq, Notion, Word, and LaTeX editors.
- When full citation management is needed, users can export standard metadata or use Zotero alongside Mereth Reader (consistent with PRD OQ-7).

### Consequence
- All source references and quick copy operations generate readable citations using the pattern:
  `{{source_author}} ({{source_year}}), p. {{page_label}}`
- If author or year is missing, the citation gracefully falls back to `{{source_title}}, p. {{page_label}}`.
- Deep links are embedded as `mereth://document/{doc_id}?page={page_label}&annotation={annot_id}`.
- Dedicated CSL style switcher is deferred past v1.
