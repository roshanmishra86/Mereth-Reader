# R6.4 — Windows Installer End-to-End Validation Runbook

## Objective & Scope

Document and execute the end-to-end validation procedure for the Mereth Reader Windows NSIS installer (`Mereth Reader_0.1.0_x64-setup.exe`), generated via Tauri 2 and GitHub Actions workflow (`.github/workflows/windows-build.yml`).

---

## 1. Installer Architecture & Layout

- **Bundle Format**: Nullsoft Scriptable Install System (NSIS) setup executable.
- **Install Mode**: `currentUser` (per-user installation, requires no UAC administrative elevation).
- **Target Installation Directory**:
  ```text
  %LOCALAPPDATA%\Programs\dev.mereth.reader\
    ├── Mereth Reader.exe
    ├── [WebView2 loader / Tauri runtime binaries]
    └── Uninstall Mereth Reader.exe
  ```
- **Application Data & SQLite Confinement**:
  ```text
  %APPDATA%\dev.mereth.reader\
    ├── db\
    │   ├── mereth.db
    │   ├── mereth.db-wal
    │   └── mereth.db-shm
    └── assets\
        └── [extracted area captures / figures]
  ```

---

## 2. File Associations & Deep Links

The installer registers:
1. **File Associations**:
   - Extension: `.pdf` (role: `Viewer`)
   - ProgID: `dev.mereth.reader.pdf` under `HKCU\Software\Classes\`
   - Open With action invoking: `"%LOCALAPPDATA%\Programs\dev.mereth.reader\Mereth Reader.exe" "%1"`
2. **Deep-Link URL Protocol**:
   - Scheme: `mereth://`
   - Registry: `HKCU\Software\Classes\mereth`
   - URL handler command: `"%LOCALAPPDATA%\Programs\dev.mereth.reader\Mereth Reader.exe" "%1"`

## 3. Clean Machine Test Matrix (Windows 11 x64)

| Step | Action | Expected Result | Pass/Fail Criteria |
| :--- | :--- | :--- | :--- |
| **1. Fresh Install** | Run `Mereth Reader_0.1.0_x64-setup.exe` without admin rights | Installs into `%LOCALAPPDATA%\Programs\dev.mereth.reader` smoothly with no UAC prompt | Files placed, Desktop/Start Menu shortcut created |
| **2. Initial Launch** | Launch via Start Menu / Shortcut | First-run empty Library displays (0 books, 0 notes, honest zero counts) | Boots within < 2.0s without crashing |
| **3. File Association** | Double-click / "Open with" 400-page PDF | Mereth Reader launches and renders document page 1 | Fast first paint, outline & page nav usable |
| **4. Deep Link Launch** | Launch `mereth://document/{id}?page=1` from Run dialog or browser | Activates reader, navigates to target document and page | Route resolves accurately |
| **5. Data Confinement** | Verify disk paths | All persistent data confined to `%APPDATA%\dev.mereth.reader\` | Zero stray files in Temp or Desktop |
| **6. Silent Install** | Execute `setup.exe /S` | Installs quietly with exit code 0 | Non-interactive deployment verified |
| **7. Clean Uninstall** | Run uninstaller from Windows Settings / Add & Remove Programs | Application binaries and shortcuts removed completely | Uninstaller leaves no orphaned registry keys |
