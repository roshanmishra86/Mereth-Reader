## 1. Threat Model & Posture

PDFs are untrusted input. Mereth Reader runs on Tauri 2 with a strict local-first security boundary:

1. **PDF Execution Lockdown (FR-8.8):**
   - PDF.js rendering options explicitly enforce `disableScripting: true` and `isEvalSupported: false`.
   - Action scanner (`scanPdfActions`) intercepts embedded `/JS`, `/JavaScript`, `/Launch`, and automatic actions (`/AA`, `/OpenAction`).
   - Verified against the hostile corpus fixture `corpus/hostile_javascript.pdf`.

2. **External Link Interception & OS-Browser Handoff:**
   - External links in document text, annotations, and markdown cannot navigate the application webview.
   - All external link clicks trigger `ExternalLinkModal` for explicit user destination disclosure.
   - System browser handoff is gated behind the Rust command `cmd_open_external_url`, which strictly accepts only `http://` and `https://` URLs, preventing arbitrary protocol execution (`file:`, `javascript:`, `data:`, `about:`, shell commands).

3. **Content Security Policy (CSP):**
   - Restrictive CSP configured in `src-tauri/tauri.conf.json`:
     `default-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' asset: data:; font-src 'self' data:;`
   - Verified by automated tests reading the live `tauri.conf.json` rather than hard-coded constants.

4. **Minimal Capability Allowlist (RK-11):**
   - `src-tauri/capabilities/default.json` contains only minimal itemized permissions: `core:default` and `dialog:allow-open`.
   - Broad filesystem permissions (`fs:*`), arbitrary shell executions (`shell:*`), and ambient network permissions are barred and asserted in CI tests.

5. **Document Text as Data (FR-12.14):**
   - Extracted document text is strictly treated as data. Control characters are stripped before processing, preventing prompt injection and formatting hijacking.
