# Mereth Reader v0.1.5

Fix the Windows title-bar close button leaving the application open. The main
window now has the Tauri permission required to close after pending note drafts
have been saved. Failed note saves continue to prevent closing to protect edits.

Download the Windows NSIS setup executable attached to this release.

This is a personal-use release. Windows installer code signing remains
unconfigured, so SmartScreen may display a warning. Update packages use the
existing updater signature mechanism. The final installer has not been manually
smoke-tested on Windows for this release.
