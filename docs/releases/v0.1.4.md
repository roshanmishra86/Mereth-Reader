# Mereth Reader v0.1.4

This personal-use release expands the reading-to-notes-to-review workflow.

- Capture quick notes with links back to the source page and selected passage.
- Work with the expanded notes workspace and recover pending note edits after interruption.
- Review cloze deletions with separate schedules per deletion and undo review ratings.
- Follow PDF links and use the updated page rendering and memory management.
- Restore backups with asset staging and recovery journals for interrupted restores.
- Fix an unhandled promise rejection when a queued note save fails; callers still receive the save error and can retry.

The database upgrades to schema 16 on first launch. Keep an independent backup
of your research before upgrading. Windows installer code signing is not
configured, so SmartScreen may display a warning. Update packages use the
existing updater signature mechanism; this is separate from Windows code signing.

On 2026-09-11, the maintainer confirmed Windows testing of the changes since
v0.1.3, including saving/reopening notes, review scheduling, and backup restore,
and authorized publication as a personal-use release after automated checks.
This is maintainer-reported evidence, not an independently observed clean-machine
installation or upgrade test of the final installer. See `RELEASE_STATUS.md` for
the evidence boundary. This is not a production-readiness certification.
